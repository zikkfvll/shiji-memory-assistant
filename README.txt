拾记  个人记忆与生活接续研究原型  v0.1
更新日期：2026-11-13

一、在这台电脑上打开
双击「启动拾记.cmd」。脚本会在本机启动服务并打开浏览器。
地址：http://127.0.0.1:8765
保留启动窗口；按 Ctrl+C 结束本次服务。关闭网页不删除记录。
若端口已被占用，脚本会停止并说明，不会关闭其他程序。

第一次使用可以新建活动，也可以点「先看看构造示例」。示例不是任何人的真实经历。
默认数据目录是 data；所有正式试用数据都在这里。test-results 只有工程验收用的构造数据。

二、已经可以做什么
1. 新建生活活动，保存短句、来源、发生时间和真实照片。
2. 区分「原内容更正」与「后来的变化」，保留旧记录，不覆盖原话。
3. 查看时间线，按关键词找记录，得到带原始依据的本地整理或回忆线索。
4. 暂停帮助、撤回记录、保存反馈与后续观察；“想起来了”不会自动成为新事实。
5. 人工复制实验材料到自己的 GPT，再导入结果、实际提示、模型标签、输入范围及引用。
6. 导出活动 JSON、全部数据和照片的 ZIP 备份；单独恢复到新目录。
7. 在「研究与启动材料」中查看完整流程、六组成对案例、候选证据卡及交流提纲。

三、当前能力的准确边界
当前运行的是透明规则检索，不是已经接入的 LLM 或新的记忆算法。
不会自动理解人物指代、抽取日期或识别照片含义；更正对象、来源与时间由人标注。
自然语言长句可能匹配不到，请先用原记录中的关键词，或留空查看当前记录。
回忆线索目前来自已保存原话和照片，不生成新的生活细节，也没有学习个人认知状态。
人工导入结果属于解释，不能当事实；模型版本、上传内容和实际输入范围须由操作者如实填写。
界面不自动调用模型，不产生 API 调用费用；本轮没有领取额度、创建密钥或复用订阅令牌。
后续通过官方 API 或符合条件的官方应用接入。额度预览不等于到账，真实余额另行核实。

仅监听 127.0.0.1，未开放手机跨设备连接或外部多用户服务。
手机尺寸布局通过桌面浏览器仿真检查，不等于真实 iPhone/Android 端到端验证。
同一台电脑账户可访问本地文件；尚无应用内账户隔离、存储加密或患者专用适配。
不要把试验原型用于用药决策、紧急救助或未经安排的患者干预。
撤回只改变有效状态，仍保留历史；永久删除需要「更多 → 删除整个活动」。已导出的备份不会同步删除。

四、备份与恢复
页面左下「导出完整备份」会下载 manifest.json 和全部照片组成的 ZIP。
原型内存备份照片总量上限约 240 MB；超过后请停止程序，再复制整个 data 文件夹备份。
恢复不会覆盖旧数据，在项目目录执行：
  .venv\Scripts\python.exe restore.py "备份文件.zip" --target "data-restored"
检查恢复内容：
  .venv\Scripts\python.exe run.py --data-dir "data-restored"
此时需先停止默认服务，避免端口冲突。
恢复命令仅支持本程序版本 1 格式、有限大小的备份；图片按原始文件保存。

五、在朋友的 Windows 电脑上安装
需要 Python 3.12 与 Node.js 22.12+ 或 24。
复制源码、research、requirements-lock.txt 和 package-lock.json；不要分享自己的 data、.env 或账号信息。
在项目目录运行：
  py -3.12 -m venv .venv
  .venv\Scripts\python.exe -m pip install -r requirements-lock.txt
  npm ci --ignore-scripts
  npm run build
然后双击「启动拾记.cmd」。不需要模型密钥即可试用离线功能。

六、运行工程验收
后端行为测试（每次使用一个新的临时目录名）：
  .venv\Scripts\python.exe -m pytest tests -q --basetemp=test-results/tmp-new-run
页面构建：
  npm run build
浏览器验收：
  先用 run.py --data-dir test-results/browser-new-run 启动隔离服务。
  使用 Playwright 运行 tests/browser.cjs，依赖通过 PLAYWRIGHT_MODULE 指向已有安装。
  此浏览器脚本会新增构造活动，不要对真实使用的数据目录运行它。
本机验证使用系统 Edge 和 Codex 随附 Playwright，未修改系统浏览器配置。
tests/fixtures/photo.png 是用于上传测试的人工单色图片，不是真实活动照片。
